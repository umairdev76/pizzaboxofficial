## BRAND & DESIGN DIRECTION

- **Vibe:** Dark, moody, premium street-food aesthetic — think warm amber/orange glows against deep dark backgrounds. Like the rooftop at night. NOT a bright, clinical fast-food look.
- **Color Palette:**
  - Primary: Deep charcoal / near-black `#0f0f0f` or `#1a1a1a`
  - Accent 1: Fiery orange-red `#FF4500` or `#E8390E` (pizza/fire energy)
  - Accent 2: Warm golden yellow `#F5A623` (cheese, warmth)
  - Text: Off-white `#F5F5F0`
  - Cards/Sections: Dark surface `#1E1E1E` / `#252525`
- **Typography:**
  - Headings: Bold, modern display font — e.g. **Montserrat ExtraBold** or **Bebas Neue**
  - Body: Clean, readable — **Inter** or **Poppins Regular**
- **Aesthetic references:** Think Zomato dark mode + high-end Pakistani restaurant brands like Roasters or Kababjees — local soul, premium feel
- **Motion:** Subtle scroll-triggered animations (fade-in, slide-up), hover glow effects on cards, parallax on hero section
- **Mobile-first:** Majority of users will be on phones — every section must look and function perfectly on mobile
- **NO stock photo generic look** — all placeholder images should be food-forward, dark-background, moody food photography style

## FUNCTIONAL REQUIREMENTS

- **WhatsApp Integration:** Every "Order Now" button should open WhatsApp with a pre-filled message like: `"Hi! I'd like to place an order from Pizza Box [Branch Name]."` using `https://wa.me/923XXXXXXXXX?text=...`
- **Click-to-Call:** All phone numbers must be tappable on mobile
- **Branch Switcher:** Persistent top bar or nav element allowing users to select their nearest branch — content (phone, map, hours) updates accordingly
- **SEO Basics:** Meta titles, descriptions, OG tags for social sharing, schema markup for `Restaurant` + `LocalBusiness` for each branch
- **Performance:** Lazy load all images, WebP format, minified CSS/JS — target under 3s load on mobile
- **Analytics:** Google Analytics 4 + Google Search Console setup
- **Cross-browser:** Chrome, Safari, Firefox, Samsung Internet (very common in Pakistan)
- **SSL & HTTPS:** Mandatory
- **Smooth scroll, sticky navbar, scroll-to-top button**
- **Social media feeds or links:** Instagram feed embed on homepage if possible (or link to @theprojectofpizzabox)

## TECH STACK RECOMMENDATION

| Option | Stack | Best For |
|---|---|---|
| **Option A (Recommended)** | Next.js + Tailwind CSS + Sanity CMS | Easy menu/branch updates by client without code |
| **Option B** | HTML/CSS/JS + EmailJS/WhatsApp API | Fastest to build, fully static |
| **Option C** | Laravel + Blade + TailwindCSS | If you want a PHP backend with a small admin panel |

If client wants to update menu prices or add promotions themselves later → go with **Option A (CMS-backed)**.

## WHAT MAKES THIS WEBSITE UNIQUE

Don't build a generic restaurant template. These are the elements that must make Pizza Box's site stand out:

1. **Rooftop Hero** — The rooftop is their single biggest differentiator in Sambrial. The homepage hero must sell this experience visually and emotionally before showing a single food item.
2. **"We Serve Happiness" Brand Voice** — Copy throughout the site should be warm, fun, and local — not corporate. Write like a Sambrial local talking to another Sambrial local.
3. **Doner Malai Pizza Spotlight** — This item is their cult favorite based on reviews. Give it its own feature treatment on the menu page and homepage (like a "Chef's Special" or "Fan Favorite" badge).
4. **Multi-Branch Feel Done Right** — Most local restaurant sites just list a phone number. This site should make every branch feel like it has its own identity while sharing the parent brand.
5. **Playland Callout** — Families with kids are a clear audience. Make the playland a featured amenity, not an afterthought.
